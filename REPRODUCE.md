# Reproducing the OCR & Chunking Benchmark

Everything needed to reproduce this benchmark from scratch is in this repo.
`data/` and `outputs/` are intentionally **not** committed — they are
regenerated by the commands below.

## Prerequisites

- **Python 3.12** (required; PaddlePaddle has no Windows wheel for Python 3.14)
  - Windows: install from python.org, then use `py -3.12`
- ~15 GB free disk (parser model weights download on first use)
- Internet access on first run (model downloads only; reruns are offline)
- CPU-only machine is fine; no GPU required

## 1. Create the environment

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Verify the interpreter (must be 3.12.x):

```powershell
python --version
```

## 2. Run the fast checks (no model downloads)

```powershell
python -m pytest -q
```

Expected: all tests pass in a few seconds.

## 3. Generate fixtures

```powershell
python -m grantbench generate-data
```

Expected: `Generated 6 scanned fixtures.` plus:

- `data/source/` — 6 authored PDFs
- `data/scanned/` — 6 image-only PDFs (the parser inputs)
- `data/ground_truth/` — 6 JSON files with blocks and valid boundaries

## 4. Run the parsers (downloads models on first use)

Activate the venv first (required so `mineru-kit` is on `PATH`), then:

```powershell
python -m grantbench parse --parser docling
python -m grantbench parse --parser paddle
python -m grantbench parse --parser mineru
```

Each should print `ok` for all six documents, e.g.:

```text
{'figure_caption': 'ok', 'lists_notes': 'ok', 'mixed_appendix': 'ok', ...}
```

First-use notes:

- **Docling** downloads layout/OCR weights from Hugging Face (~1–2 GB).
- **PaddleOCR** downloads ~11 PP-StructureV3 sub-models to
  `%USERPROFILE%\.paddlex` (formula model is the slowest, ~1 min).
  The oneDNN workaround for PaddlePaddle 3.3.x is applied automatically.
- **MinerU** downloads VLM/layout weights (~3–4 min on first document only).
- Approximate CPU runtimes per document: PaddleOCR ~100 s,
  MinerU ~10–15 s, Docling ~8–20 s.

If one parser fails, its error is recorded in
`outputs/raw/<parser>/<document>/failure.json` and the other parsers still
complete.

## 5. Run chunking, evaluation, and reports

```powershell
foreach ($parser in @("paddle", "mineru", "docling")) {
    foreach ($strategy in @("hierarchical", "sectional", "paragraph", "heading")) {
        python -m grantbench chunk --parser $parser --strategy $strategy
    }
}
python -m grantbench evaluate
python -m grantbench report
```

Or the single-command equivalent (re-runs parsing too):

```powershell
python -m grantbench run-all
```

## 6. Expected outputs

- `outputs/raw/<parser>/<document>/` — 18 dirs with native JSON/Markdown/assets,
  `benchmark.md`, and `run.json` (tool, version, options, wall-clock time)
- `outputs/normalized/<parser>/` — 18 canonical block JSON files
- `outputs/chunks/<parser>/<strategy>/` — 72 chunk JSON files
- `outputs/metrics/metrics.json` — 90 metric rows (`evaluate` prints the count)
- `outputs/reports/`
  - `all_metrics.csv` — full detail table (includes `cer`)
  - `summary.md` — parser/chunker/runtime tables
  - `ocr_comparison.png` — WER / CER / Type F1 / Order LCS per parser
  - `chunking_comparison.png` — boundary F1 / heading context per chunker
  - `parser_chunker_heatmap.png` — parser × chunker heatmaps

## Configuration

All run settings live in `config.toml`:

```toml
[benchmark]
device = "cpu"
chunk_token_budget = 180
parsers = ["paddle", "mineru", "docling"]
chunkers = ["hierarchical", "sectional", "paragraph", "heading"]
documents = []   # empty = all fixtures; or list stems, e.g. ["tables"]
```

Point the CLI at another config with
`python -m grantbench --config path/to/config.toml <command>`.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `mineru-kit is unavailable` | Activate the venv (`.venv\Scripts\Activate.ps1`) so its `Scripts/` dir is on `PATH` |
| PaddlePaddle oneDNN `NotImplementedError` | Already handled in-repo (`PADDLE_PDX_ENABLE_MKLDNN_BYDEFAULT=False` on CPU); make sure you installed `requirements.txt` under Python 3.12 |
| Hugging Face symlink warnings on Windows | Harmless; or enable Developer Mode / set `HF_HUB_DISABLE_SYMLINKS_WARNING=1` |
| `No normalized output … Run parse first` | Run the `parse` step for that parser before `chunk` |
| `No metric rows …` from `report` | Run `evaluate` after successful `parse` + `chunk` steps |
| Slow first run | Normal — one-time model downloads plus CPU inference; reruns reuse cached weights |

## What is NOT reproduced byte-for-byte

- Absolute paths inside `run.json` (`input`, `command`) reflect your machine.
- `duration_seconds` varies with hardware.
- Metric values should match within rounding on the same fixture set, since
  fixtures are generated deterministically by `generate-data`.
